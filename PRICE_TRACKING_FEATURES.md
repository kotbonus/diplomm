# Функциональность отслеживания цен

## Обзор
Реализована система автоматического отслеживания цен для товаров в wishlist с возможностью уведомлений о скидках.

## Основные возможности

### 1. Автоматическое получение цен с сайтов
- Поддержка популярных магазинов: Ozon, Wildberries, AliExpress, Яндекс.Маркет
- Универсальный парсинг для других сайтов
- Определение цен с помощью различных селекторов и регулярных выражений

### 2. Выбор способа ввода цены
- **Ручной ввод**: пользователь вводит цену самостоятельно
- **Автоматическое получение**: цена получается с сайта по ссылке
- Переключение между режимами через чекбокс

### 3. Уведомления о скидках
- Автоматическое определение скидок при снижении цены
- Отображение процента скидки
- Визуальные индикаторы (красные значки скидки)
- Показ оригинальной цены и текущей цены со скидкой

### 4. Массовое обновление цен
- Кнопка "Обновить цены" на главной странице wishlist
- Обновление всех товаров с включенным автоотслеживанием
- Уведомления о количестве обновленных цен и скидок

## Техническая реализация

### Новые поля в модели WishlistItem
```java
- originalPrice: double // Оригинальная цена
- autoPriceTracking: boolean // Флаг автоматического отслеживания
- lastPriceUpdate: LocalDateTime // Время последнего обновления цены
- discountAvailable: boolean // Наличие скидки
```

### Сервисы
- **PriceParsingService**: парсинг цен с веб-страниц
- Обновленный **WishlistService**: поддержка новых полей и методов

### API эндпоинты
- `POST /api/parse-price` - получение цены с указанного URL
- `POST /api/update-prices` - массовое обновление всех цен

### Обновленные шаблоны
- **add-item.html**: форма добавления с опцией автоотслеживания
- **edit-item.html**: форма редактирования с поддержкой цен
- **wishlist.html**: отображение скидок и кнопка обновления

## Использование

### Добавление товара с отслеживанием цены
1. Введите ссылку на товар
2. Появится опция "Автоматически отслеживать цену с сайта"
3. Отметьте галочкой для включения автоотслеживания
4. Нажмите "Получить цену с сайта" для автоматического определения цены
5. Цена будет автоматически обновляться при изменениях на сайте

### Обновление цен
1. На странице wishlist нажмите кнопку "🔄 Обновить цены"
2. Система проверит все товары с включенным автоотслеживанием
3. Обновит цены и покажет уведомление о результатах
4. При наличии скидок будут показаны красные значки с процентом

### Визуальные индикаторы
- **Красный значок "Скидка X%"**: показывает текущую скидку
- **Зачеркнутая цена**: оригинальная цена до скидки
- **🔄 Автообновление цены**: индикатор включенного отслеживания

## Зависимости
Добавлена библиотека Jsoup (1.17.2) для парсинга HTML-страниц.

## Примечания
- Парсинг работает для большинства популярных российских интернет-магазинов
- Для некоторых сайтов может потребоваться настройка селекторов
- Цена обновляется только при явном запросе (кнопка "Обновить цены")
- Все цены хранятся в рублях
