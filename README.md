см# Docker Веб-сайт

Простой веб-сайт на Spring Boot, работающий в Docker контейнере.

## 🚀 Быстрый запуск

### С использованием Docker Compose (рекомендуется)

```bash
docker-compose up --build
```

### С использованием Docker

```bash
# Сборка образа
docker build -t my-website .

# Запуск контейнера
docker run -p 8080:8080 --name my-website my-website
```

## 📱 Доступ к сайту

После запуска сайт будет доступен по адресу:
- http://localhost:8080

## 🌐 Страницы сайта

- **Главная страница** - `/` - приветствие и текущее время
- **О сайте** - `/about` - информация о технологиях и проекте
- **Приветствие** - `/hello` - персонализированное приветствие
  - `/hello?name=ВашеИмя` - приветствие с конкретным именем

## 🛠 Технологический стек

- **Java 21** - язык программирования
- **Spring Boot 3.2.0** - фреймворк
- **Thymeleaf** - шаблонизатор
- **Maven** - система сборки
- **Docker** - контейнеризация

## 📁 Структура проекта

```
src/
├── main/
│   ├── java/grpc/demo/
│   │   ├── DiplomApplication.java     # Основной класс приложения
│   │   └── controller/
│   │       └── WebController.java     # Веб-контроллер
│   └── resources/
│       └── templates/
│           ├── index.html             # Главная страница
│           ├── about.html             # О сайте
│           └── hello.html             # Приветствие

├── docker-compose.yml                 # Docker Compose конфигурация
└── pom.xml                           # Maven зависимости
```

## 🔧 Полезные команды

### Остановка контейнера
```bash
docker-compose down
# или
docker stop my-website
```

### Просмотр логов
```bash
docker-compose logs -f
# или
docker logs -f my-website
```

### Перезапуск контейнера
```bash
docker-compose restart
# или
docker restart my-website
```

## 🐳 Особенности Docker конфигурации

- Используется многоэтапная сборка для оптимизации размера образа
- Порт 8080 пробрасывается на хост-машину
- Настроен health check для мониторинга состояния контейнера
- Автоматический перезапуск при сбоях

## 🌟 Возможности сайта

- Адаптивный дизайн для разных устройств
- Поддержка русского языка
- Динамическое контента на сервере
- Персонализированные приветствия
- Современный UI с CSS стилями

## 📝 Разработка

Для локальной разработки без Docker:

```bash
# Запуск через Maven
./mvnw spring-boot:run

# Или через IDE запустить DiplomApplication.java
```

Сайт будет доступен по тому же адресу http://localhost:8080
