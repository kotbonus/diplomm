🎁 О сайте Wishlist

Ваш персональный менеджер желаний

🌟 Добро пожаловать в мир ваших желаний!

Описание сайта

🛠️ Технологический стек

Java 21
Spring Boot 3.2.0
Thymeleaf
Maven
Docker
HTML5 & CSS3

🚀 Особенности проекта

  • Полностью контейнеризированное приложение
  • Современный стек технологий
  • Интуитивный и красивый интерфейс
  • Полная поддержка русского языка
  • Адаптивный дизайн для всех устройств
  • Управление приоритетами желаний

💡 Функциональность

  • Добавление неограниченного количества желаний
  • Категоризация по типам товаров
  • Установка приоритетов
  • Отслеживание статуса покупки
  • Добавление ссылок на товары
  • Фильтрация по категориям

🐳 Как запустить

Для запуска сайта используйте Docker:

docker build -t wishlist-app . docker run -p 8080:8080 wishlist-app

Или используйте docker-compose:

docker-compose up

После запуска приложение будет доступно по адресу: http://localhost:8080
